Mini Social Media Platform

A simple mini social media application built to demonstrate core full-stack development concepts and fundamental social media functionality.

Overview

This project implements essential features of a social media platform with a clean and minimal user interface.
It focuses on backend logic, database relationships, and basic frontend integration, making it suitable for learning and internship-level development.

Features

User authentication (signup & login)

User profiles

Create and view posts

Like and comment on posts

Follow / unfollow users

Clean and minimal user interface

Structured and maintainable codebase

Tech Stack

Frontend

HTML

CSS

JavaScript

Backend
Express.js

Database

Relational database for users, posts, comments, and followers


UI & Design

Simple and minimal UI

Designed for clarity and usability

Easy to convert into functional frontend code

Focus on functionality over visual complexity
